# Octopus FDE 场景开发指南

Octopus FDE 场景开发指南面向负责数字员工方案设计、装配和交付的 FDE。它关注如何把客户业务场景转成 team 内数字员工方案、能力组合、运行路径和验收标准。

FDE 的核心任务，是让数字员工从“能对话”走向“能完成业务闭环”。一个可交付方案应同时说明业务目标、触发方式、输入上下文、执行能力、结果落点和验收方法。

本指南按 FDE 的实际工作顺序组织：先分析业务场景，再设计 team 内数字员工方案，再组合触发、任务、企业环境访问、数据知识和应用开发能力，最后完成验收。

## 核心原则

- 从业务闭环出发，而不是从工具清单出发。
- 数字员工工作在 team 内，能力授权、数据访问、设备、Secret、计划任务和消息触达都应围绕 team 设计。
- 能用结构化数据解决的问题，不长期依赖临场对话。
- 高频网页操作应沉淀为可复用流程。
- 任何对外发送、数据写入或系统操作，都应有清晰的结果落点和验收方式。
