# Browser 与 WebSkill 条件设计

状态：仅在清单中的浏览器或 WebSkill 条件成立后纳入项目；本文件自身不授权访问任何站点。

## 触发事实

记录必须浏览网页、操作受控页面或调用 WebSkill 的已确认需求、目标类别、数据来源和能力证据。

## 设计

说明允许的导航或调用范围、输入输出、会话隔离、失败重试、页面变化处理和需要人工确认的提交动作。

## 身份与权限风险

核对登录身份、站点授权、Cookie 与凭据隔离、提示注入、下载内容、外部发送和不可逆操作边界。

## 验收

覆盖允许页面、越界域名、未登录、页面变化、恶意内容、提交前取消和审计证据，禁止把读取授权扩大为写入授权。
